# YOLO Dataset Manager

[< Back to Dataset Manager](../README.md)

## Overview
The **YOLO Dataset Manager** is a Python-based tool designed to create YOLO-compatible datasets for object detection, instance segmentation, and pose estimation. It processes images and their corresponding segmentation masks (generated by AutoSegmentor), applies augmentations, and organizes them into a structured YOLO format (`train`, `valid`, `test`).

## Features
- **YOLOv8/v11 Compatibility**: Generates standard folder structures and `data.yaml` files.
- **Advanced Augmentation**: Integrated support for blur, noise, and color jitter via PyTorch and Albumentations.
- **Multithreaded Processing**: Leverages multiple CPU cores for rapid dataset synthesis.
- **Mask-to-Polygon Conversion**: Converts color-coded segmentation masks into normalized YOLO polygon annotations.
- **Flexible Splitting**: Configurable train/val/test ratios (e.g., 80/10/10).
- **GPU Acceleration**: Uses CUDA for image transformations if available.

## How It Works
The tool operates in three primary phases:
1. **Structure Creation**: `create_yolo_structure.py` builds the target directory tree.
2. **Data Transformation**: `DatasetCreator.py` iterates through the AutoSegmentor `workspace/` data.
3. **Annotation Synthesis**: Masks are converted to text-based YOLO labels with class IDs and coordinates.

### Workflow
- **Input**: Raw images and masks from `workspace/working_dir/verified/`.
- **Processing**: For each image, the generator creates multiple augmented versions (default: 10x).
- **Output**: A standalone dataset directory ready for training.

## Installation
Ensure you are in the project root virtual environment:
```bash
pip install numpy opencv-python pillow torch torchvision tqdm
```

## How to Use
1.  **Configure**: Open `DatasetCreator.py` and update the `CONFIG` dictionary.
    - `dataset_path`: Point this to your AutoSegmentor `workspace/working_dir/`.
    - `class_to_id`: Map your object names to integer IDs.
    - `color_to_label`: Map mask RGB colors to class IDs.
2.  **Run**:
    ```bash
    python DatasetCreator.py
    ```

## Directory Structure
```
AutoSegmentor/
└── DatasetManager/
    └── YolovDatasetManager/
        ├── DatasetCreator.py            # Main generation script
        ├── create_yolo_structure.py      # Folder and YAML builder
        └── <dataset_output_dir>/         # Generated YOLO dataset
```

## Troubleshooting
- **Mask Color Mismatch**: Ensure the `color_to_label` mapping exactly matches the colors defined in `autosegmentor/ui/UITheme.py`.
- **OOM during Augmentation**: Reduce `num_threads` if your system runs out of memory during parallel processing.
